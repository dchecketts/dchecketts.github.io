First, we'll start with an explanation of binary logic and how it relates to booleans in Python.

<Heading level={"h2"}>Binary & Booleans</Heading>

Simply put, binary can be thought of 1 being equal to `True` and 0 being `False`. If that's enough of an explanation, feel free to skip to the next section. Otherwise, read on.

Binary means that there are two states; 1 and 0, on and off, true and false. Binary, though often used with computers, predates them. Early in computer history, the machines were large and used vacuum tubes. These tubes made it more reasonable to use binary, or the comparisons between whether a tube was "on" or "off". As a base 2 system, it differs from the base 10 that we usually use, and it's interesting to see how the two compare.

| Base 10 | Binary |
| :---: | :---: |
| 0 | 0 |
| 1 | 1 |
| 2 | 10 |
| ... | ... |
